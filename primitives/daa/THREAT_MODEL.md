# DAA — Threat Model

Test:

- duplicate/conflicting awards;
- stale or substituted authority source;
- beneficiary substitution;
- policy substitution;
- purpose/resource scope confusion;
- amount-bound escalation;
- expired awards;
- award replay/version confusion;
- an upstream recommendation being treated as authority without a DAA award;
- an award being treated as reserved/committed capital;
- an award being treated as claim encumbrance;
- an award being treated as replay/lane assignment;
- downstream action exceeding the award;
- validator disagreement hidden behind an authority grant;
- generic underwriting/ranking logic silently expanding DAA's semantic scope.
